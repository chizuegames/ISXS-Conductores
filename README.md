# ISXS Conductores

Selector web estático de conductores para IllicitSpeed XS. Abre `index.html` o publica el repositorio con GitHub Pages; no necesita instalación ni servidor de aplicaciones.

- Las flechas dibujadas en la imagen cambian de conductor. La selección empieza en PJ0.
- El candado pequeño en la esquina superior izquierda fija al conductor actual y desactiva ambas flechas. Al tocarlo de nuevo, se puede volver a cambiar de conductor.
- Tocar un personaje muestra su habilidad; mantenerlo pulsado unos 650 ms muestra su descripción.
- PJ1–PJ6 y PJ13 (Miuna) están disponibles de inicio. Miuna aparece inmediatamente después de PJ6. PJ7–PJ12 (incluido Kumi) y PJ18 llevan la capa `BL.png`; cada uno se desbloquea con la clave `24680`.
- Mantener pulsado PJ0 permite revelar PJ14–PJ17 (Maicy, Worgen, Mei y Kohei) con la clave `13579`.
- La interfaz completa, incluidos los cuadros de información, se presenta girada 90° hacia la izquierda. Cada habilidad se muestra sobre un panel translúcido del color de su conductor.
- Los desbloqueos se recuerdan en el almacenamiento local de ese navegador. Estas claves son parte de la experiencia del juego; como todo el código de la página es público, no sirven para proteger información confidencial.

Los archivos `PJ0.png` a `PJ18.png` y `BL.png` deben estar junto a `index.html`.
